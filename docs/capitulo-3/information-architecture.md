### 3.1.2. Information Architecture

La información de ANITEC se organiza según las tareas de ganaderos y veterinarios. Ambos perfiles comparten el acceso a su cuenta y suscripción, pero disponen de opciones diferentes para gestionar animales, vinculaciones y atenciones.

#### 3.1.2.1. Organization Systems

La aplicación organiza el contenido por perfil y por función.

| Perfil      | Contenido principal                                                                                                                  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Ganadero    | Inventario de animales, observaciones, veterinarios vinculados, próximas visitas, historial de atenciones e indicaciones de cuidado. |
| Veterinario | Ganaderos vinculados, invitaciones, visitas programadas, registro de atenciones, tratamientos, vacunas e indicaciones de cuidado.    |
| Ambos       | Información de la cuenta, suscripción y cierre de sesión.                                                                            |

Se utiliza una organización jerárquica para pasar de los listados a sus detalles. Por ejemplo, desde el inventario se accede al perfil del animal y luego a sus observaciones o atenciones.

Las visitas se organizan por fecha y el historial de atenciones permite consultar los registros anteriores. El registro de cuenta y la verificación del correo siguen una secuencia de pasos.

La landing page agrupa la presentación del producto, sus funcionalidades, los perfiles de usuario y la información del equipo.

#### 3.1.2.2. Labelling Systems

Las etiquetas utilizan términos en español relacionados con las actividades de los usuarios. Los botones indican la acción que se realizará y los títulos identifican el contenido de cada pantalla.

| Etiqueta                | Propósito                                         |
| ----------------------- | ------------------------------------------------- |
| Mi ganado               | Consultar el inventario del ganadero.             |
| Registrar animal        | Agregar un animal al inventario.                  |
| Agregar observación     | Registrar información observada por el ganadero.  |
| Historial de atenciones | Consultar las atenciones registradas del animal.  |
| Indicaciones de cuidado | Consultar las instrucciones del veterinario.      |
| Programar visita        | Definir una próxima visita veterinaria.           |
| Registrar atención      | Registrar la atención realizada al animal.        |
| Mi suscripción          | Consultar el plan y su estado.                    |
| Mi cuenta               | Acceder a la información y opciones de la cuenta. |

Los iconos acompañan las etiquetas para facilitar su reconocimiento. Se mantiene el mismo nombre para una acción en las distintas pantallas.

#### 3.1.2.4. Searching Systems

La búsqueda facilita la ubicación de animales dentro del inventario y de ganaderos dentro de los listados del veterinario. Se utilizan datos reconocibles, como el nombre o el código del animal.

Los resultados conservan información básica que permite distinguir cada registro antes de abrir su detalle. Cuando no se encuentran coincidencias, se muestra un mensaje que permite al usuario revisar su búsqueda.

La landing page presenta su contenido mediante secciones y no requiere un buscador interno para esta primera versión.

#### 3.1.2.5. Navigation Systems

La aplicación utiliza una navegación principal según el perfil del usuario. Desde ella se accede a las funciones habituales y a la cuenta.

Los listados permiten abrir el detalle de un animal, ganadero, visita o atención. Las pantallas de detalle incluyen opciones para continuar con las acciones relacionadas y regresar a la pantalla anterior.

Los formularios y ventanas de confirmación permiten completar o cancelar una operación. Las acciones que modifican información muestran su resultado para que el usuario pueda reconocer lo ocurrido.

En la landing page, los enlaces de navegación permiten desplazarse entre las secciones de presentación, funcionalidades e información del equipo.
