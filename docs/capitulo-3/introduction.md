# Capítulo III: Solution UI/UX Design

Este capítulo presenta el diseño de la experiencia de uso y las interfaces de ANITEC. Incluye las guías de estilo, la organización de la información y los diseños de la landing page y la aplicación móvil.

## 3.1. Product design

El diseño de ANITEC se desarrolla a partir de las historias de usuario de ganaderos y veterinarios. Se representa mediante wireframes, mock-ups, diagramas de navegación y un prototipo interactivo.
