# Capítulo II: Requirements Development and Software Solution Design

Este capítulo reúne el análisis de competidores, las entrevistas y la identificación de las necesidades de los usuarios. A partir de estos elementos se definen los requisitos, los contextos del dominio y la arquitectura de software de ANITEC.

## 2.1. Competidores

Se comparan Livestock Manager, Herdwatch y AgriWebb para reconocer las alternativas disponibles e identificar oportunidades de diferenciación para ANITEC. El análisis considera sus funcionalidades, usuarios, precios, canales de distribución, fortalezas y debilidades.
